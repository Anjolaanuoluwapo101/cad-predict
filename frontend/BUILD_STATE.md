# Build state (frontend/)
Stack: Vite + React, three + @react-three/fiber + drei. API default http://127.0.0.1:8000 (VITE_API_URL overrides). CORS allows http://localhost:5173.
Design: clinical imaging suite. Light + dark via [data-theme] on <html>, tokens in src/styles/tokens.css. Fonts: Instrument Serif (display/numerals), Geist (body). Risk scale teal > amber > crimson from colour_score. Wording: "Lower likelihood / Borderline / Elevated likelihood", never "positive". Probabilities shown as >99% / <1% at extremes.
Layout plan: intake (form left, heart right) -> assessment (slim rail, camera pushes in, dashboard right).
Model: public/models/heart_groningen_split.glb, meshes named RCA, LAD, LCX, LeftMain (grey, not a target), plus Heart_body etc. No node transforms.
Targets: CAD (overall), LAD, LCX, RCA. RCA = logreg, explanation_units log-odds; others rf, probability.
Rule: SHAP only (no LIME). Housekeeping backend fixes parked.
